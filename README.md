# Meraj Uddin Malik — Portfolio

Personal portfolio website showcasing my projects, skills, and professional journey. Built with Next.js, React, and Tailwind CSS for a fast, responsive, and modern experience.

Live Site: https://merajuddinmalik.netlify.app

## Tech Stack

Next.js 14 (App Router), React 18, Tailwind CSS, Radix UI / shadcn components, Framer Motion animations, and EmailJS for the contact form.

## Pages

Home, Work (projects), Services, Resume, and Contact.

## Getting Started

Clone the repo and install dependencies, then run the dev server:

git clone https://github.com/Meraj-Uddin-Malik/MyPortfolioSite.git
cd MyPortfolioSite
npm install
npm run dev

Then open http://localhost:3000 in your browser.
